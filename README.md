# Learning Predator–Prey Interactions from Real-World Animal Behavior 🦈🐟

This repository accompanies our paper on learning predator–prey dynamics from synthetic and real-world animal trajectories using Generative Adversarial Imitation Learning (GAIL).

The framework models predator and prey with separate role-specific policies and discriminators and applies alternating co-training to their conflicting behavioral objectives. Synthetic Couzin-based demonstrations are used for controlled verification before applying the same architecture to trajectories reconstructed from aquarium recordings.

## Abstract

<p align="justify">
Understanding how local interactions give rise to coordinated collective behavior is important for both biological research and decentralized robotic systems. Traditional models rely largely on hand-crafted interaction rules, while data-driven approaches have mostly focused on homogeneous groups or synthetic demonstrations. Here, we introduce a co-evolutionary generative adversarial imitation learning framework for heterogeneous predator–prey behavior. Separate predator and prey policies combine pairwise interaction and attention networks with role-specific discriminators, allowing both roles to learn distinct strategies through reciprocal interactions. We first validate the framework on controlled predator–prey trajectories generated by an extended Couzin model and then apply it to trajectories reconstructed from biological recordings. In the synthetic setting, the learned policies closely reproduce predator proximity and preserve the direction of several behavioral responses, although pursuit and escape alignment remain weaker than in the expert. On biological data, overall collective motion is captured more closely than directional pursuit and escape responses. These results demonstrate the feasibility of learning role-specific heterogeneous collective behavior from biological observations while highlighting tightly coupled inter-species interactions as a key challenge for imitation learning. Such policies could ultimately support heterogeneous multi-robot systems with asymmetric roles without relying on hand-crafted interaction rules.
</p>

## Code and Data Access

The repository can be set up with Anaconda as follows:

1. Clone the repository and enter the project directory.

   ```bash
   git clone https://github.com/wirthy21/ICRA2027-PredatorPreyGAIL.git
   cd ICRA2027-PredatorPreyGAIL
   ```

2. Create and activate a dedicated environment.

   ```bash
   conda create -n PredatorPreyGAIL python=3.12 -y
   conda activate PredatorPreyGAIL
   ```

3. Install the dependencies required for the paper analyses.

   ```bash
   pip install -r "Paper Analysis/requirements_analysis2.txt"
   ```

4. Download the accompanying datasets from [OneDrive](https://1drv.ms/f/c/e86ec4f701d097f4/IgCQUyQfwzltSLD6Ojpz2aFxAa7X_cVoBMCKVs6FVY3137c?e=XdhcqM).
